A collection of front-end development projects created as part of my **Front-End Libraries Certification** journey. This repository showcases practical web development skills through interactive applications, games, and creative user interfaces.

Each project focuses on applying front-end concepts, improving problem-solving skills, and building engaging web experiences.

## 📌 About This Repository

This repository contains five front-end projects:

* 💱 **Currency Converter** — A currency conversion project with a dedicated user interface and stylesheet.
* 🎮 **Tic-Tac-Toe Game** — An interactive game featuring a game board and gameplay logic.
* 🐾 **Digital Pet Game** — An interactive digital pet application built with state management.
* 🧠 **Flashcard Quiz App** — A flashcard-based application with quiz functionality.
* 📸 **Photography Exhibit** — A photography exhibition project focused on presenting visual content.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sairam-saridi/front-end-libraries-certification.git
```

### 2. Navigate to the Project

```bash
cd front-end-libraries-certification
```

### 3. Explore the Projects

Open the project folder you want to explore and review its source files.

Each project has its own HTML entry point and associated source files. The JSX and TypeScript projects may require a compatible development or build environment to run, depending on their implementation.
